# Before the Siege

[Explore the castle](https://syymza.github.io/castle-siege/)

A human-scale castle preparing for a siege. Walk through the gatehouse and courtyard, climb to the battlements, operate the defences and begin a short watch-and-alarm scene.

## Controls

Desktop: W A S D to walk; drag or use arrow keys to look. Phone: the left thumb pad walks; drag elsewhere to look. Tap a nearby gate for its action, or use Defences. Begin watch starts the event and enables optional horn audio; Replay watch restarts it. Gates remain manual.

## Static release

Open index.html directly for offline use, or serve this directory. The renderer, models and textures are embedded. No backend, account, analytics or runtime asset service is required. A current browser with WebGL2 and DecompressionStream is needed. GitHub Pages serves main at the repository root.

This release preserves the reviewed scene from source revision ad899e2d7b1a5ecae6671a81eee1dd4d725a38e5. Only two internal asset-source identifiers were removed from the public HTML metadata. No gameplay or visual changes were made. The public repository intentionally contains only the static release and credits; development history, task logs and QA recordings are excluded.

## Limits

This is a stylized historical composite, not a surveyed reconstruction or battle simulation. Hall and tower interiors are closed; distant terrain is scenery. There is no combat. Phone testing uses browser emulation on a Mac, not a physical iPhone; device performance and audio support vary. See CREDITS.md and THIRD-PARTY-LICENSES.txt.
