# Credits and rights

The castle is an illustrative late-thirteenth-century western European composite, inspired by Welsh and Marcher castles. It is not a surveyed reconstruction or a precise historical simulation.

Architecture, environment geometry, costume, horn, rigging, animation, scene logic and synthesized audio were made for this project. No third-party recordings or heritage photographs are included. No additional license grant is made for project-original material; third-party material retains the licenses below.

## Inhabited-scene additions

The stores shelter, supply cart and containers, water/repair props, hall and wall details, and tent kit are original authored geometry. Existing CC0-derived material textures are reused; the photographic sky is credited below. The tent form takes reference from Morgan Library M.638 folio27v (Paris, circa1244–1254): https://ica.themorgan.org/manuscript/page/54/158530 . No reference image is bundled. Camp layout, dimensions and activity are illustrative rather than a reconstruction of a named army.

Near guard and medium worker anatomy derive from Blender Studio Human Base Meshes v1.4.1 (CC0), with original costume, texture derivatives and rig work. The published runtime contains authored scene assets, not engineering fixtures.

Far armored silhouettes: original project geometry and vertex palette, 498 triangles; shared project animation rig. Civilian work costume and CarryCrate: original project assets using existing shared materials. The crate uses the shared material atlas.

Functional well and woodworking props are original project geometry using the existing shared wood, iron and hemp materials. The well is an illustrative bounded haul/inspection mechanism; no water filling is simulated. The restrained woodworking task does not claim progressive cutting or material removal.

- Sky: [Kloofendal48dPartlyCloudy PureSky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), Greg Zaal and Jarod Guest, Poly Haven CC0. Official sky-only photographic panorama resized to1024×512 and aligned to the existing light; tonemapped LDR, not full HDR lighting.
